annoyed that your agents stop working when your mac locks?

made agent guard so you can leave it unlocked when you step away. keeps your macbook awake, blocks most physical input, and keeps the screen clear for agents doing visual work.

> blocks ordinary keyboard + mouse input
> touch id / apple watch approval to stop
> doesn’t hide your screen or stop software / remote input
> system gestures can bypass it; a crash stops protection

not as safe as actually locking your computer, but a little more peace of mind.

open source. try it.
https://github.com/KartikC/agent-guard
